# Organizer App Features
# Travi SaaS - Organizer Account

This document outlines the user interface menus and corresponding features for the **Organizer** role.

---

## 1. Dashboard Overview
A high-level view of the organizer's business performance.

- **Metrics & KPIs:** Total active tours, total bookings, total revenue.
- **Recent Activity:** Latest bookings, upcoming tours, and pending transport requests.

## 2. Tours Management
The core workspace for creating and managing tour packages.

- **Tour List:** View all owned tours with their status (Draft, Published, Archived).
- **Tour Creation/Editing:**
  - Enter basic details: title, description, location, duration (days), capacity.
  - Set pricing (price per person).
  - Define accommodation and travel time info.
  - Configure transport requirements (none, self-provided, or external).
- **Itinerary Builder:** Add and edit day-by-day itineraries (title, description) for each tour.
- **Publishing:** Publish tours to make them visible to Travelers (requires Admin approval of the profile).
- **Archiving:** Archive older tours to hide them from search without deleting historical booking data.

## 3. Bookings
Monitor and manage customers who have booked tours.

- **Booking List:** View all bookings specifically for the organizer's tours.
- **Traveler Manifest:** See a list of travelers for a specific tour date.
- **Booking Details:** Track booking status (Pending, Confirmed, Canceled) and total revenue per booking.

## 4. Transport Requests
Coordinate with Transporters for tours requiring external transportation.

- **Transporter Discovery:** Filter and search approved transporters by service areas and availability.
- **Send Requests:** Create a transport request including dates, pickup/dropoff locations, and required seats.
- **Request Tracking:** View the status of sent requests (Pending, Accepted, Declined, Canceled, Completed).

## 5. Profile & Settings
Business profile management.

- **Business Info:** Manage organizer type (Individual or Company). Set company name, display name, and business description.
- **Contact Details:** Update phone number and physical address.
- **Transport Flags:** Toggle the "Provides transportation" flag if self-hosting transport.
